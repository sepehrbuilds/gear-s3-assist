# Using Gear Assist

Open the watch app. Press upper Back or tap the microphone, wait for recording/listening, speak and press Back again to send. Bezel rotation changes gain while idle. Home remains the watch's normal system button; Back control requires the app in the foreground. Exit/cancel stops a capture and the backend turn as applicable.

Home commands show short structured results on the watch, without HomePod announcements. General answers show short text and play through HomePod when it is available. The result can distinguish unsupported, unavailable, jammed or unconfirmed outcomes. If speech playback is unavailable, a text answer can remain on the watch.

Use the connection panel to check the watch service, Mac backend, HA and whether cloud inference is configured. A configured label is not a paid live model health probe. The ordinary Mac browser preview lacks private watch control and cannot independently connect; its Connecting screen does not describe the physical watch's state.

A single audio client is admitted per dedicated endpoint. Capture is bounded near 19 seconds. Keep Wi-Fi/Mac dependencies available. Recognition and audible latency vary; do not rely on the prototype for emergency access control.

## Reversible changes

Snapshot client/audio/websocket, private config and the matching signed UI before updates. Restore a matching set with the same owner, mode and SMACK attributes; restart only the affected Gear unit and verify on hardware. Existing private snapshots and firmware backups stay outside this public tree.

Backend flags can independently disable optional ASR warm-up or Gear audio streaming. Pause previews stay disabled in the selected configuration. Applying a backend config requires the correct idle service restart and live endpoint verification. Restore exact matching private snapshots for a source rollback; examples are not a replacement for real credentials.

Watch autostart uses only the two Gear-specific wants links and the policy service; retain private policy/credentials/backups if disabling them. A root-capable boot snapshot is not a factory-stock restoration guarantee. No firmware change is required for these routine source/config reversions.
